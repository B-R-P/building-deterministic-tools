# Building Deterministic Tools

A skill for turning repetitive, detail-sensitive analysis into a small,
deterministic tool with verifiable output.

Use it when missing even one item is costly (large datasets, generated markup,
APIs, document corpora). It helps agents:

- extract deterministically instead of manual scanning;
- retrieve targeted results without losing completeness; and
- verify output against source ground truth.

For one-off or low-risk tasks, direct inspection is usually simpler.

## What you get

- guidance for building a compact, queryable tool;
- an overview plus focused retrieval commands; and
- independent verification patterns.

Details are in
[`SKILL.md`](skills/building-deterministic-tools/SKILL.md) and
[`verification-patterns.md`](skills/building-deterministic-tools/verification-patterns.md).

## Installation

```bash
npx skills add B-R-P/building-deterministic-tools
```
